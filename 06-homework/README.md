## 📂 დავალებების სტრუქტურა

### 1. `task-1-manual-coding/` — მარტივი ხელით დასაწერი დავალება
* **თემა:** „ონლაინ ბიბლიოთეკა / წიგნების კატალოგი“
* **მიზანი:** დამოუკიდებლად, AI-ის გარეშე, ხელით დაწეროთ კომპონენტები და გადასცეთ Props.
* **შესაქმნელი კომპონენტები:**
  * `BookCard.jsx`: იღებს `title`, `author`, `price`, `rating`, `isBestSeller`, `categories`.
  * `LibraryHeader.jsx`: სათაური და წიგნების მრიცხველი.
* **მოთხოვნები:**
  * Props დესტრუქტურიზაცია და Default Props.
  * პირობითი რენდერინგი (`isBestSeller` ბეიჯისთვის).
  * სიების რენდერინგი `.map()` მეთოდით და უნიკალური `key` ატრიბუტით.

### 2. `task-2-find-and-fix-errors/` — შეასწორე არსებული შეცდომები
* **⚠️ კოდში დაშვებულია ზუსტად 7 შეცდომა!**
* **მიზანი:** შეცდომების დიაგნოსტიკა, JSX-ის წესების, Virtual DOM-ისა და Props-ის შეზღუდვების გააზრება.
* **დაშვებული შეცდომების ჩამონათვალი (შესამოწმებლად):**
  1. კომპონენტის სახელი პატარა ასოთია დაწერილი (`buggyUserCard` ნაცვლად `BuggyUserCard`).
  2. გამოყენებულია `class=` ნაცვლად `className=`-ისა.
  3. `<img>` ტეგი არ არის დახურული (self-closing).
  4. კომპონენტი აბრუნებს რამდენიმე sibling ელემენტს ერთიანი მშობლის / Fragment-ის გარეშე.
  5. Props-ის მუტაციის მცდელობა (`props.score = ...`). Props არის მხოლოდ წაკითხვადი!
  6. `.map()`-ში არ არის მითითებული `key` ატრიბუტი.
  7. `style` ატრიბუტში გადაცემულია სტრიქონი `style="..."` ნაცვლად ობიექტისა `style={{ ... }}`.
