## 📝 რეკომენდებული პრომპტის შაბლონი AI-სთვის

შეგიძლიათ გამოიყენოთ ეს პრომპტი თქვენს AI ასისტენტთან:

```text
შენ ხარ Senior React დეველოპერი. დამეხმარე ავაწყო პატარა React კომპონენტები "MovieHub" აპლიკაციისთვის ლექცია 3-ის ცოდნის ფარგლებში (JSX სინტაქსი, კომპონენტების ჩაშენება და Props-ის გადაცემა).

მოთხოვნები:
1. შექმენი MovieCard.jsx კომპონენტი:
   - იღებს props: title, year, genre, rating, posterUrl, onAddToWatchlist, isInWatchlist.
   - იყენებს Props destructuring-ს და default props-ს.
   - აჩვენებს რეიტინგის ვარსკვლავებს, გამოშვების წელს და ჟანრის თეგს.
   - ღილაკი "Watchlist-ში დამატება" (თუ უკვე დამატებულია, ეწეროს "დამატებულია ✓" და იყოს გათიშული).

2. შექმენი FilterBar.jsx კომპონენტი:
   - იღებს ჟანრების მასივს (genres) და მიმდინარე აქტიურ ჟანრს (selectedGenre).
   - იღებს onSelectGenre callback ფუნქციას props-ით.
   - ღილაკების სია რენდერდება .map()-ით და key ატრიბუტით.

3. შექმენი WatchlistSummary.jsx კომპონენტი:
   - იღებს watchlistItems მასივს და აჩვენებს შერჩეული ფილმების რაოდენობას.

წესები:
- კოდი უნდა იყოს მხოლოდ .jsx ფორმატში, inline styles-ით.
- დაიცავი React-ის ყველა წესი: ერთი მშობელი/Fragment, className, self-closing ტეგები, key პროპი .map()-ში.
- დაწერე სუფთა და კომენტარებით გაჯერებული ქართული კოდი.
```

## 🔍 რა უნდა შეამოწმოთ AI-ის დაგენერირებულ კოდში? (Checklist)

- [ ] იწყება თუ არა ყველა კომპონენტის სახელი დიდი ასოთი (PascalCase)?
- [ ] ხომ არ გამოიყენა AI-მ `class=` ნაცვლად `className=`-ისა?
- [ ] არის თუ არა ყველა ტეგი დახურული (`<img />`, `<input />`)?
- [ ] აქვს თუ არა `.map()`-ით რენდერირებულ ყველა ელემენტს უნიკალური `key`?
- [ ] სწორად არის თუ არა გამოყენებული Props დესტრუქტურიზაცია?
- [ ] გადაეცემა თუ არა Callback ფუნქციები სწორად (`onClick={() => ...}`)?
